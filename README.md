## 이런 걸 할 수 있어요

| | |
|---|---|
| **모아 보기** | 캐릭터 카드(PNG·JSON), 페르소나, 월드인포, NovelAI 시나리오·로어북, 프롬프트 프리셋, QR을 한 번에 불러와요. 종류는 알아서 나눠요. |
| **정리하기** | 폴더 · 태그 · 카테고리 · 즐겨찾기 · 검색. 같은 이름 카드와 다른 버전은 묶어서 보여 줘요. |
| **읽기** | 항목마다 접고 펼치기, 토큰 수, 카드 안 검색(형광펜), 그리팅별 복사. |
| **번역하기** | 구글 번역(무료) 또는 내 AI 키(Gemini · Vertex AI · Claude · OpenAI · Ollama). 번역은 저장되고, 직접 고칠 수도 있어요. |
| **고치기** | 편집 화면, 찾기·바꾸기(프리셋 · 정규식), 로어북 편집, HTML 꾸밈 정리, 프로필 자동 정리(NAME · AGE · SEX …). |
| **내보내기** | 실리태번 PNG 카드, 페르소나 파일, 월드인포, 프롬프트·QR, NovelAI 시나리오·로어북, 마리나라 엔진 페르소나로 받아요. 불러온 원본 그대로도 받아요. |
| **꾸미기** | 기본 테마와 매표소(티켓) 테마, 다크 모드, 포인트 색, 고양이 8종, 글꼴 고르기와 내 글꼴 넣기. |
| **그 밖에** | 랜덤 뽑기, 원본 도장, 백업(ZIP)으로 기기 옮기기. |

## 시작하기

1. **열기** — 웹 주소로 들어가거나, 안드로이드 앱을 설치해요.
2. **가져오기** — `+` 버튼으로 파일을 고르거나 끌어다 놓아요. 여러 개를 한 번에 골라도 돼요.
3. **보고 고치기** — 카드를 누르면 상세보기, 연필을 누르면 편집이에요.
4. **백업하기** — 설정 › 데이터 › 백업으로 가끔 받아 두세요.

> 웹은 PC·휴대폰 브라우저 어디서나 설치 없이 열려요. 크롬·삼성 인터넷·엣지에서 가장 잘 돼요.

## 데이터와 보안

> [!IMPORTANT]
> **카드는 내 기기 안에만 저장돼요.** 서버로 보내지 않아요.
> 그래서 브라우저 기록·사이트 데이터를 지우거나 앱을 삭제하면 카드도 함께 사라져요. **백업을 꼭 받아 두세요.**

> [!CAUTION]
> **AI 키(API 키)는 이 기기의 냥카이브 안에만 저장돼요.**
> - 여러 사람이 쓰는 PC나 남의 기기에서는 키를 넣지 마세요.
> - 쓸 수 있는 금액·사용량에 한도를 걸어 둔 키를 쓰세요.
> - 더 쓰지 않으면 설정에서 키를 지우고, 키 발급처에서도 삭제해 주세요.
> - 번역할 때는 카드 글이 고른 번역 서비스(구글 또는 AI 회사)로 보내져요.

## 백업할 때

> [!WARNING]
> **백업 ZIP의 압축을 풀었다가 다시 압축하면 안 돼요.** 그렇게 다시 만든 ZIP은 냥카이브가 읽지 못해요.
> 용량을 줄이려고 한 번 더 압축하고 싶다면, 백업 파일을 **그대로 통째로** 다른 압축 파일에 넣어 주세요. 불러올 때는 그 바깥 압축만 풀고 원래 백업 파일로 불러오면 돼요.

- 카드가 많으면 백업이 여러 ZIP(`1of3`, `2of3`…)으로 나뉘어요. 불러올 때는 **나뉜 파일을 모두 함께** 골라 주세요.
- 같은 카드가 이미 있으면 백업 내용으로 덮어써요.

## 페르소나를 실리태번에 넣을 때

실리태번은 **같은 파일 이름의 페르소나가 이미 있으면 덮어쓰지 않고 건너뛰어요.** 실리태번에서 페르소나를 지운 뒤에도 설정에 기록이 남아 있어 마찬가지로 건너뛰어요.

그래서 냥카이브는 페르소나를 **내보낼 때마다 새 파일 이름**으로 내보내요.

- 실리태번에 넣을 때마다 **냥카이브에서 새로 내보낸 파일**을 쓰세요. 예전에 받은 같은 파일을 다시 넣으면 건너뛰어요.
- 새 페르소나로 추가되니, 실리태번에 예전 것이 남아 있다면 필요 없는 쪽은 실리태번에서 지워 주세요.

## 카드가 많을 때

2천 장 정도까지 무리 없이 쓸 수 있어요.

- **저장 공간:** 카드 그림 크기에 따라 1천 장에 0.5~2GB쯤 필요해요. 기기 공간을 넉넉히 비워 두세요.
- **백업 · 불러오기:** 장수와 그림 용량만큼 시간이 걸려요. 끝날 때까지 앱을 닫거나 화면을 끄지 말아 주세요.
- 오래된 기기에서는 처음 열 때 조금 느릴 수 있어요.

## 자주 묻는 질문

<details>
<summary><b>실리태번에서 그대로 쓸 수 있나요?</b></summary>

네. 받은 PNG 카드는 실리태번 형식(v2 · v3)을 지켜요. 고친 칸만 바뀌고, 정규식 · 깊이 프롬프트 · 확장 데이터는 그대로 남아요.
</details>

<details>
<summary><b>불러온 파일을 그대로 다시 받을 수 있나요?</b></summary>

네. 내보내기에서 **원본**을 고르면 불러온 파일 그대로 받아요. 냥카이브에서 고친 뒤에도 원본은 따로 보관돼 있어요. 고친 내용으로 받으려면 **지금 버전**을 고르세요.
</details>

<details>
<summary><b>마리나라 엔진에서도 쓸 수 있나요?</b></summary>

페르소나는 내보내기 형식에서 **마리나라**를 고르면 마리나라 엔진용 파일로 받아요. 여러 장을 한꺼번에 내보낼 때도 고를 수 있어요.
</details>

<details>
<summary><b>카드가 많아도 괜찮나요?</b></summary>

수백~천 장도 괜찮아요. 백업이 크면 여러 개의 ZIP으로 나눠 받고, 불러올 때 한꺼번에 고르면 돼요.
</details>

<details>
<summary><b>앱을 설치할 때 경고가 떠요.</b></summary>

구글 플레이 밖에서 받는 앱이라 그래요. "출처를 알 수 없는 앱" 설치를 허용하면 돼요.
</details>
